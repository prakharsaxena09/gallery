Place your background music file here as:  romantic.mp3

Tips:
- Use a ROYALTY-FREE / no-copyright romantic instrumental so the invite can be
  forwarded freely on WhatsApp without copyright muting. Good sources:
  Pixabay Music, YouTube Audio Library, Uppbeat (free tier with attribution).
- Keep it small (under ~2–3 MB) so it loads fast on mobile data.
- The file path is set in js/main.js -> CONFIG.musicSrc

If no file is present, the invite still works perfectly — it just opens silently.
